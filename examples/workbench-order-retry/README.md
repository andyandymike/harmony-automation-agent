# 订单付款失败后重试恢复

用一个本地订单页回归付款重试和库存查询。主用例有 15 个顶层步骤，引用的「准备测试订单」片段可以单独打开。付款与库存请求均由本机测试服务处理。

## 在工作台运行

使用 Harmony Agent Workbench 0.20.33 和运行时 0.1.0a11 或更新版本。在仓库根目录启动本机服务，并保持终端运行。

```powershell
node .\examples\workbench-order-retry\serve.cjs
```

1. 在工作台选中已连接并解锁的鸿蒙手机。到「网络调试」的「测试网关」，点「配置路由」，把「开发上游地址」设为 `http://127.0.0.1:18991`，保存路由，启动网关并连接手机。
2. 用手机自带浏览器打开 `http://127.0.0.1:18990/workbench-order/`，保持「订单回归测试」页在前台。
3. 在「测试」中打开「订单付款失败后重试恢复」并点「运行」。也可以用「打开文件」选择 [主用例](order-retry/workflow.json)。随用例保存的规则组会在对应步骤自动启停。

## 验证结果

| 场景 | 预期 |
| --- | --- |
| 引用「准备测试订单」 | 重置页面，读取订单编号，键入测试订单号，确认结果与读取值一致 |
| 首次启用付款和库存规则 | 付款返回 `503 → 503 → 200`，失败分支恰好重试两次 |
| 按名称关闭付款规则 | 付款返回上游 `200`，库存继续命中自身规则并返回 `409` |
| 再次启用同名付款规则 | 付款再次返回第一条 `503`，响应序列从头开始 |
| 关闭两个规则组 | 付款和库存都返回上游 `200`，页面通过两项最终断言 |

在「运行配置与调试」的「断点与单步调试」里，选第 15 个步骤「点击 查询库存」。停住时可以用下面的定位器检查按钮，执行一步后可在网络记录看到 `409`，继续即可完成回放。

```json
{"bundleName":"com.huawei.hmos.browser","type":"button","text":"查询库存"}
```

该浏览器的网页输入框暴露了名称和焦点状态。片段用控件定位聚焦「输入订单号」，用键入动作输入固定测试值 `QA-042`，再对照从页面读到的订单编号验证确认结果。

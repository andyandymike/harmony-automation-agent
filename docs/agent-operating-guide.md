# Agent operating guide

The maintained operating workflow is now the [Harmony Agent Skill](../skills/harmony-agent/SKILL.md). It covers CLI discovery, device/session selection, fresh observations, actions with assertions, input/scroll limits and uncertain outcomes.

See [Skill setup](skill-setup.md) to install it. The CLI can also be used directly without installing a Skill; [agent usage](agent-usage.md) remains a quick reference.

# 0.1.0a2 验证记录

日期：2026-11-03（Asia/Tokyo）。这是本地 alpha 的实际验证记录，不等同于跨设备支持或公共发布。

## 本轮变化

- 读取失败或取消后统一使旧 ref 失效。
- 全选后、删除前重新核验焦点；清空后、输入前再次检查焦点。
- 动作已下发或已确认后发生取消/异常，保留部分执行状态和证据。
- 启动身份首次变得可读时记录新身份、更新 epoch 并使旧观察失效。
- `fill` 默认预算改为 15 秒；`wait` 以及业务 `expect` 默认仍为各自 5 秒。显式预算优先，输入与业务断言分别计时。
- 新增可重复离线打包与干净环境安装检查，以及 Agent 调用记录工具。

沿用 Windows / Python 3.12.10 / HDC 3.2.0d / UiTest 6.0.2.3 / API 24 模拟器，4 CPU、4 GB、1256 × 2760。专用测试实例中选择小艺输入法基础模式（设置页说明不收集个人数据）并完成 26 键布局初始化。该初始化由本轮测试准备完成，CLI 不自动同意输入法提示。

[输入记录](validation-input-alpha2.json)包含两个真实 TextInput 的 6 次检查，中文写入、替换和清空均通过。普通输入框与关闭软键盘输入框的结果分别记录；不能由一个控件推断任意 IME/应用都支持。

## 独立 Agent 任务

独立 Agent 只获得自然语言任务、明确设备/应用、CLI 入口以及普通调用指南；不提供源码、既有验证脚本、目标 selector 或前轮诊断。设备串行分配，任务组之间重置 fixture。调用入口记录 CLI 进程墙钟耗时和 UTF-8 输出字节数，原始屏幕输出留在本地私有状态目录。

额外测试一次回执丢失：真实 `press` 执行并获得成功回执后，测试包装器将一次返回替换为 `dispatched=unknown`。这仅模拟回执丢失，不修改 CLI 正式行为。由日志与最终状态检查 Agent 是否先观察再继续，不能把模拟回执当作真实 HDC 故障。

[Agent 汇总](validation-agent-alpha2.json)中两组各 5 个任务，**10 项完成，0 项未完成**。A 组完成计数、通知开关、Order B、延迟加载和终点滚动，并由主执行者重新读取设备复核全部最终结果。B 组完成普通中文提交、完整替换、清空、native 中文提交及 Reset；前四项复核原始新鲜观察，Reset 再独立读取设备确认。

| 指标 | A：交互与回执丢失 | B：中文表单 |
| --- | ---: | ---: |
| CLI 调用数 | 26 | 19 |
| 已记录 CLI 执行耗时合计 | 38.503 秒 | 41.703 秒 |
| 首次 CLI 开始至最后 CLI 完成的窗口 | 503.614 秒 | 402.571 秒 |
| 原始 CLI stdout | 596,529 字节 | 565,263 字节 |

窗口时间包含调用之间的 Agent 推理与工具调度，排除最初读指南和最后文字回复；不能当成单个 CLI 的执行时间。A 组有一次非法 `--target` 参数调用：子 CLI 返回了正确 JSON 错误，但当时的记录包装器再次解析参数后抛异常，漏记该次耗时。因此 A 的 CLI 耗时合计少这一条，未补造耗时；原始错误输出已保留。该包装器缺陷已修复并加入回归，指南也明确位置参数规则。

回执丢失后下一条命令确为 `observe`，读到 Counter: 1，随后累计只执行三次增加，最终 Counter: 3。B 组有一次 PowerShell 捕获中文输出导致解析失败，Agent 未重发输入，重新观察确认值后继续；已补充 UTF-8 捕获指南并单独验证其 JSON 往返。

本轮证明了这些指定任务可以完成，也暴露了输出量和调用准备成本：两组原始 stdout 都超过 550 KB。未来可研究按应用/任务缩减观察和复用帮助信息；该数据不能直接等同模型实际消耗的上下文。

不能取得外层模型的实际 token 统计，因此不把字节、字符或命令数转换为 token。模型规划与工具调用整体耗时、CLI 时间分别记录。本轮 Agent 是内部独立线程，不能算作外部人类使用者试用。
